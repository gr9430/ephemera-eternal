# Posters, Zoom and Format-Switch Confirm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add letter and legal portrait poster formats with a fixed credit line and "pile" Randomize, plus editor zoom and a confirm before a format switch clears the pages.

**Architecture:** One shared `PAGE_SIZES` table in `js/store.js` drives the canvas, margins, preview and PDF size for every format. Posters are one-page formats like `single-page`; the credit strip is DOM drawn by `updateCanvasFormat()` (never an element). Zoom is view-only state (`state.viewZoom`) folded into the existing rotation transform and into `clientToSheet()`, the single screen→sheet mapping. Poster Randomize is a new pure `composePile()` in `js/randomize.js` reusing the booklet composer's helpers.

**Tech Stack:** Plain browser JS (no build), html2canvas 1.4.1 + jsPDF 2.5.1 from cdnjs, Node for unit tests (`node js/<name>.test.js`), Playwright + headless Chromium for browser checks (`tests/browser/*.cjs`).

**Spec:** `docs/superpowers/specs/2026-10-08-posters-design.md`

**No commits.** Glenn is still testing server-side and is not committing yet. Where a task would commit, it instead ends with a full Node test run. Do not run `git add`/`git commit`.

## Global Constraints

- Format values exactly `poster-letter` and `poster-legal`; labels exactly `Poster - Letter (8.5" × 11")` and `Poster - Legal (8.5" × 14")`.
- Sheet sizes in px at 96/in: half-letter 528×816, single-page 1056×816, stapled 1056×816, poster-letter 816×1056, poster-legal 816×1344. PDF points = px × 0.75.
- Poster PDF file names: `poster-letter-YYYY-MM-DD.pdf`, `poster-legal-YYYY-MM-DD.pdf`. Existing names unchanged (`zine-single-page-folded-…`, `zine-single-page-stapled-…`, `zine-booklet-…`).
- Credit text lives in `data/poster.json` as `{ "credit": "…" }`; initial text exactly `Made at Ephemera Eternal · The AWG Foundation · photographs on loan from Adam Goldman`.
- Credit strip: 20px tall, bottom edge 24px above the sheet's bottom, above every element, not selectable, not in saved projects, posters only.
- Zoom: 25%–200%, 25% steps; Fit ≤ 100%; view-only (never saved, never in the PDF); reset to Fit on format change, project load, autosave restore at startup, and booklet Randomize.
- Confirm text exactly: `Switching format clears this zine's pages. Continue?`
- The info form (`state.meta`) is never cleared by a format switch.
- Piles never use flyers (`data/gallery.json`).
- No new dependencies in the app. 4-space indent, existing comment density.
- Every browser check needs the env from Task 1:
  `export NODE_PATH=~/.cache/ephemera-eternal-tools/node_modules CHROME_PATH=~/.cache/ms-playwright/chromium_headless_shell-1223/chrome-headless-shell-linux64/chrome-headless-shell`
  and is run from the repo root.

// Single-page, stapled and posters: each sheet as drawn (stapled has one editor page per side)
async function buildSheetPdf() {
    const { jsPDF } = window.jspdf;
    const { w, h } = sheetSize();
    const pw = w * PT_PER_PX, ph = h * PT_PER_PX;
    const orientation = pw > ph ? 'landscape' : 'portrait';
    const pdf = new jsPDF({ orientation, unit: 'pt', format: [pw, ph] });
    const indexes = state.pageFormat === 'stapled' ? state.pages.map((_, i) => i) : [state.currentPage];
    for (let i = 0; i < indexes.length; i++) {
        if (i > 0) pdf.addPage([pw, ph], orientation);
        const canvas = await captureEditorPage(indexes[i]);
        pdf.addImage(canvas.toDataURL('image/png'), 'PNG', 0, 0, pw, ph);
    }
    return pdf;
}

// poster.js — the fixed credit line along the bottom of every poster. Text comes from
// data/poster.json; like Glenn's info page it is never in state.pages, so it can't be
// selected, moved or deleted, and isn't in saved projects.

const Poster = {

    init: function () {
        fetch('data/poster.json')
            .then(r => r.json())
            .then(data => {
                Poster.credit = data && typeof data.credit === 'string' ? data.credit.trim() : '';
                updateCanvasFormat();

// The credit strip for a poster sheet, or null when there is no credit text
function buildPosterCredit() {
    if (!Poster.credit) return null;
    const strip = document.createElement('div');
    strip.className = 'poster-credit';
    strip.textContent = Poster.credit;
    return strip;
}

const ZOOM_MIN = 0.25, ZOOM_MAX = 2, ZOOM_STEP = 0.25;
const ZOOM_GUTTER = 20;   // .canvas-rotator's margin on each side

// Largest zoom (≤ 100%) at which a sheetW × sheetH sheet, turned by rotation, fits an areaW × areaH area
function fitZoom(areaW, areaH, sheetW, sheetH, rotation) {
    const sideways = (rotation || 0) % 180 !== 0;
    const boxW = sideways ? sheetH : sheetW;
    const boxH = sideways ? sheetW : sheetH;
    const zoom = Math.min(1, (areaW - 2 * ZOOM_GUTTER) / boxW, (areaH - 2 * ZOOM_GUTTER) / boxH);
    return Math.max(ZOOM_MIN, Math.floor(zoom * 100) / 100);
}

// The next 25% step up (direction 1) or down (-1); zoom may be off the grid after Fit
function stepZoom(zoom, direction) {
    const steps = zoom / ZOOM_STEP;
    const next = direction > 0 ? Math.floor(steps + 1e-9) + 1 : Math.ceil(steps - 1e-9) - 1;
    return Math.min(ZOOM_MAX, Math.max(ZOOM_MIN, next * ZOOM_STEP));
}

// Poster Randomize: raw material dropped around the middle of the sheet for the participant to
// arrange. Each text entry: [grammar symbol, fewest, most, font list, [smallest, largest size]]
const PILE_RECIPES = {
    'protest': {
        texts: [['slogan', 1, 1, 'display', [40, 56]], ['origin', 2, 3, 'readable', [16, 22]]],
        photos: [1, 2], clips: [2, 3]
    },
    'show-flyer': {
        texts: [['band_name', 2, 4, 'display', [28, 44]], ['venue', 1, 1, 'display', [24, 36]], ['show_detail', 1, 2, 'readable', [16, 22]]],
        photos: [0, 0], clips: [2, 3]
    }
};
const PILE_SPREAD = 0.2;   // centres land within ±20% of the sheet from its middle
const PILE_TILT = 15;      // degrees either way

function composePile({ kind, page, line, clipart, photos, fonts, rng, newId, measure }) {
    const recipe = PILE_RECIPES[kind];
    if (!recipe) return [];
    const r = randomTools(rng);
    const c = { r, newId, page, measure: measure || ((content, font, fontSize, w) => textHeight(content, fontSize, w)) };
    const nextPhoto = makePool(photos, r), nextClip = makePool(clipart, r);
    // Top-left corner that puts a w × h box's centre at a random spot in the middle of the sheet
    const spot = (w, h) => ({
        x: page.w / 2 + r.float(-PILE_SPREAD, PILE_SPREAD) * page.w - w / 2,
        y: page.h / 2 + r.float(-PILE_SPREAD, PILE_SPREAD) * page.h - h / 2
    });
    const tilt = () => r.float(-PILE_TILT, PILE_TILT);
    const pictures = [], texts = [];

    const addPicture = item => {
        if (!item) return;
        const w = r.int(200, 320), h = Math.round(w * r.float(0.75, 1.33));
        const at = spot(w, h);
        pictures.push(randomImage(newId, item, at.x, at.y, w, h, tilt(), page));
    };
    for (let i = r.int(...recipe.photos); i > 0; i--) addPicture(nextPhoto());
    for (let i = r.int(...recipe.clips); i > 0; i--) addPicture(nextClip());

    // band_name belongs to the grammar project; until it exists, single band words stand in
    const say = symbol => line(symbol) || (symbol === 'band_name' ? line('band') : '') || '';
    for (const [symbol, fewest, most, list, [small, large]] of recipe.texts) {
        for (let i = r.int(fewest, most); i > 0; i--) {
            const content = say(symbol);
            if (!content) continue;
            const w = r.int(260, 340);
            const font = r.pick(fonts[list]), fontSize = r.int(small, large);
            const at = spot(w, c.measure(content, font, fontSize, w));
            texts.push(randomText(c, { x: at.x, y: at.y, w, content, font, fontSize, rotation: tilt(), align: 'center' }));
        }
    }
    return [...pictures, ...texts];
}

## Posters

**Poster - Letter (8.5" × 11")** and **Poster - Legal (8.5" × 14")** are one portrait sheet, one
side. "Save as PDF" gives one page at that paper size (`poster-letter-YYYY-MM-DD.pdf`,

A credit line runs along the bottom of every poster, just above the margin. Participants can't
edit or cover it. Edit the wording in `data/poster.json` (`credit`); keep it under about 120
characters so it fits on one line.

**Randomize** on a poster asks for a **Protest pile** (slogans, neighborhood lines, photos, clip
art) or a **Show flyer pile** (band names, a venue, show details, clip art) and drops it around
the middle of the sheet, on top of whatever is there. Nothing is replaced; participants arrange,
edit or delete the pieces. The show-flyer pile reads the grammar symbols `band_name`, `venue` and
`show_detail`; until `band_name` exists it uses single `band` words, and a symbol that's missing
is left out.

## Zoom and switching formats

**−**, **+** and **Fit** in the top bar zoom the sheet on screen (25%–200%) in every format. Fit
shows the whole sheet, never above 100%, and is applied whenever the format changes or a project
opens. Zoom is view-only: it isn't saved and doesn't change the PDF.

Changing **Format** clears the zine's pages, so it asks first when they hold anything. The Your
info form keeps its values; **Fill in page** puts them back on the page.
